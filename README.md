# ZMP — Zapret Modifications Patcher

Кросплатформленое tui приложение для удобной установки и управления модами на проекты вроде **[zapret-discord-youtube](https://github.com/flowseal/zapret-discord-youtube)**, **[zapret2](https://github.com/bol-van/zapret2)** и **[zapret-discord-youtube-linux](https://github.com/Sergeydigl3/zapret-discord-youtube-linux)**. ✨

---

## Ключевые возможности

- 🗂️ Каталог модов из любого GitHub-репозитория: каждый релиз репозитория — это мод (как в [peachoff/Zapret-Mods](https://github.com/peachoff/Zapret-Mods))
- 📦 Установка модов напрямую из локального ZIP-архива

## Использование

Пока что проект не получится полноценно использовать. Описание появится вместе с первым релизом в скором времени.
