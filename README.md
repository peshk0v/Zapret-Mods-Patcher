# ZMP — Zapret Modifications Patcher

by **peshk0v**


## Быстрая установка мода

### Windows

1. Скачай `zmp.bat`
2. Положи его в папку с Zapret
3. Перетащи ZIP-архив мода на `zmp.bat`
4. Готово!

Если `.bat` лежит в папке Zapret, путь определится автоматически. Если архив лежит отдельно — скрипт попросит указать путь к Zapret.

Также можно запустить `zmp.bat` без аргументов и ввести оба пути вручную.

### Linux / macOS

1. Скачай `zmp.sh`
2. Сделай исполняемым: `chmod +x zmp.sh`
3. Запусти: `./zmp.sh /path/to/mod.zip`

Или без аргументов — скрипт запросит пути интерактивно.
